About this app

Built for field use during Nova Scotia fish habitat studies. The species reference tool and dichotomous key are for morphological identification only — there is no camera-based or ML photo identification in this version. If a catch can't be confidently identified in the field, log it as unidentified — see key and photograph it for follow-up.

Species diagnostic data is sourced from FishBase, DFO, GBIF, ACCDC, and NS government/peer-reviewed references. See README for full citations and known data gaps.
